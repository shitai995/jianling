# 原版还原工作清单

本清单用于后续开发和逐项验收。当前仅在 Unity Game 窗口测试，保持编辑器后台状态；暂不打包。状态依据现有源码与已保存报告，不用工作量百分比代替验收结论。后续新增功能从现有模块扩展，固定资源继续在编辑期保存。

## 本阶段目标与总清单

目标是先把原版已有游戏流程还原成可编辑、可继续扩展的 Unity 工程。当前不做打包；历史里程碑的“95%”只是工作量估算，不代表游戏已完成，也不作为本清单的完成率。
