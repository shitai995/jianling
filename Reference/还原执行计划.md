# 古剑魂梦还原执行计划

确定日期：2026-10-30。目标是根据已核验的原安装包恢复完整单机玩法，并交付能够持续扩建的 Unity 工程。后续工作按本计划推进，每一阶段以可运行结果和新验证证据验收。

## 固定技术路线

- 使用现有 Unity 2D 工程、原图与动作数据；保留剧情、任务、规则、关键动作节拍和命中语义。
- 当前开发基线锁定本机已验证的 Unity 2022.3.62f2c1。Unity 6.3 升级作为最后的独立兼容试验，避免与玩法迁移同时改动。
- 运行时界面逐页改为 uGUI Prefab，输入逐步接入 Input System；每次替换一个可验收范围，旧页面继续工作。
- 以小接口收拢输入、游戏操作、战斗事件和存档协调，复用已有库存、装备、交易、奖励和技能模块。
- 先还原原版数值；明确区分移植问题、正常难度问题与后续平衡修改。
- MCP 连接当前工程、后台加载与运行、取帧和验证。每批记录源码指纹及验证范围，保护正式存档与历史报告。

## 执行方法

1. 读取当前状态并明确这一批的改动、资产和验证范围。
2. 实施生产代码及需要保存的原生资产，不只创建验证夹具或演示窗口。
3. 通过 MCP 导入与编译，运行受影响的模块及集成验证，检查真实 GameView 画面。
4. 将结果保存在按阶段区分的目录；验证失败先修复，不能以菜单调用成功代替验证通过。
5. 更新本文件的阶段状态及开发记录，再推进下一批。无需逐个常规步骤重新确认。
